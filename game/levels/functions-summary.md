You now have the everyday toolkit: identity, constant functions, composition, argument reordering, and dependent application. Two moves did all the work. `λ-intro` meets a function goal by introducing its argument, and application uses a function you already hold.

Next: pairs. A function takes one argument at a time, so to carry two values together you need a product type. That is the next chapter.
