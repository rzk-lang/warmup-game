You now have the core operations on equality: `refl`, reversal, concatenation, the action of a function, and transport. Each came from a single move, path induction: to reason about an arbitrary path, it is enough to handle the `refl` case.

Beyond this lie the path-algebra laws, unit and associativity up to higher paths, and results like Eckmann–Hilton. They are all built from exactly these operations.
