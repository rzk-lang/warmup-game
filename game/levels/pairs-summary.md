You can now bundle two values into a pair, project them back out with `first` and `second`, and move between a function on pairs and a two-argument function. The Σ-type extends all of this to the dependent case, where the type of the second component may depend on the first value.

Next: propositions as types, where these same pairs and functions start to read as logic.
