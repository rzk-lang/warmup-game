Welcome. This template is a tiny game you can fork and rewrite. Each level is an example of one authoring feature, kept as small as possible so the shape is easy to read.

The mathematics never goes beyond a single idea. A **morphism** $x \to y$ in a type $A$ is a path along the directed interval $\Delta^1$. The simplest one is the identity at $x$: a path that stays put. Every puzzle here is a one-liner over that substrate. Read a level, open its file under `game/levels/`, and copy what you need.
